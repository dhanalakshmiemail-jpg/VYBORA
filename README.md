
# VYBORA 🎬
### Your Universe of Entertainment

VYBORA is a modern entertainment discovery platform designed to help users explore movies, web series, and music through a visually immersive and interactive experience.

## ✨ Features

- 🎥 **Entertainment Discovery** – Explore trending movies, popular series, and new releases.
- 🎵 **Music Discovery** – Browse music collections and discover new entertainment.
- 🔍 **Smart Search** – Find content using titles, genres, and categories.
- 🎭 **Mood-Based Discovery** – Discover entertainment based on your mood.
- 🎲 **Surprise Me** – Find something unexpected to watch or explore.
- ❤️ **Personal Library** – Organize your favourite entertainment.
- 🧠 **Interactive Quizzes** – Test your entertainment knowledge.
- 🔐 **Authentication UI** – Login, registration, and password recovery interfaces.
- 📱 **Responsive Design** – Enjoy a consistent experience across desktop, tablet, and mobile.
- 🌈 **Premium UI** – Cinematic visuals, modern layouts, smooth animations, and vibrant accents.

## 🛠️ Technologies Used

## 🚀 Getting Started

### Prerequisites

Install Node.js and npm on your computer.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/VYBORA.git
   ```

2. Navigate to the project folder:

   ```bash
   cd VYBORA
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
